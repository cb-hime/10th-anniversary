Birthday AR

使い方
1. このフォルダに、お祝い動画を「movie.mp4」という名前で入れてください。
2. フォルダ内は以下の状態にします。

birthday-ar/
├── index.html
├── style.css
├── script.js
├── targets.mind
└── movie.mp4

3. GitHub Pages / Netlify など HTTPS で公開してください。
4. 公開URLをスマホで開き、「START」を押してカメラを許可します。
5. Tシャツのデザインにカメラを向けると、初回だけ動画が全画面再生されます。

動画を変更する方法
- 新しい動画を同じ「movie.mp4」という名前で上書きするだけです。
- index.html / script.js / targets.mind は変更不要です。

推奨動画
- MP4
- H.264映像 + AAC音声
- 縦動画でも横動画でもOK
- 容量はできれば50MB以下（通信環境により小さいほど安定）

注意
- 標準カメラ単体では動きません。最初に公開URLをブラウザで開く必要があります。
- iPhoneでは音声付き動画の自動再生に制限があるため、このページでは最初のSTART操作を入れています。
- Tシャツのシワが強い場合は認識しにくくなるので、なるべく平らにしてください。
